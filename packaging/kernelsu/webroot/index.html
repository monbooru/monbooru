Open the gallery

The library is a web app of its own, so it opens in your browser rather than in this page. Copy the address above; it works on this phone, and on other devices once server.bind_address is not a loopback one.

Configuration

/data/adb/monbooru/monbooru.toml holds the gallery path, the port and the data directory. Edit it, then Restart. Set server.bind_address = "0.0.0.0:8455" and server.base_url to reach the library from other devices.

Uninstalling

Removing the module stops the server and leaves /data/adb/monbooru alone: the gallery database, the config and the log stay where they are.
